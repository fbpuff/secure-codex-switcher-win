## Why

The account detail repeats `Account availability` and the internal label `Bottleneck-aware score`, which does not explain what a value such as 13.6 means. The desktop shortcut name is also too long for the standard Windows icon label width.

## What Changes

- Replace the duplicated detail labels with one `Account availability` row and an interactive question-mark explanation.
- Explain the exact formula, bottleneck meaning, one-decimal presentation, and distinction from official quota.
- Rename only the desktop/start-menu shortcut to `Codex Switcher` while preserving the formal product and executable identity.
- Remove the exact retired shortcut created by this app to avoid duplicate desktop entries.

## Capabilities

### New Capabilities

- `detail-score-help`: Defines the accessible account-detail score explanation.
- `short-shortcut-name`: Defines the shorter shortcut name and precise legacy cleanup behavior.
