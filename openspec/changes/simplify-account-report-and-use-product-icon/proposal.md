# Change: Simplify account report and use the product icon

## Why

Observed quota-change totals are difficult to interpret and do not belong in the primary account comparison table. The internal CSS brand mark also differs from the packaged product icon.

## What Changes

- Remove observed quota changes from the primary account table.
- Rebalance the remaining five columns and reduce row height.
- Keep actual detected resets in the dedicated reset-history section.
- Audit reset detection tests for independent 5h and 7d windows and false-positive resistance.
- Use the packaged product icon inside the application shell.
